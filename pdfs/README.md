# PDFs

Every PDF in this folder is published as a flipbook. The newest (by the date in
the file name) is shown first; the rest appear in the archive.

Name files `YYYY-MM-DD Title.pdf` or `YYYY-MM Title.pdf`, for example
`2026-10 Autumn Newsletter.pdf`. Files without a date use the date they were uploaded.

Upload: https://github.com/opmedia-dev/flipbook/upload/main/pdfs
